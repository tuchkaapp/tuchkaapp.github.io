Какие данные нужны для работы приложения

Для входа и работы с файлами Тучка использует данные аккаунта и авторизации, содержимое выбранных файлов, фотографии и видео, названия и расположение папок, а также сведения, необходимые для отображения и выполнения операций с файлами.

Если вы обращаетесь по вопросам работы приложения или своих данных, сведения из обращения нужны для разбора вопроса. Не присылайте пароли, коды входа и лишние персональные данные.

Где и как используются данные

Приложение обращается к серверной части сервиса для авторизации и выполнения операций с файлами. Данные аккаунта, папки и файлы отображаются в приложении; загрузка, скачивание и другие файловые операции требуют обмена данными с сервером.

Когда вы передаёте ссылку на файл, учитывайте, что она может предоставить получателю доступ к его содержимому. Не передавайте ссылки на личные документы людям, которым вы не хотите открывать эти данные.

Разрешения устройства

Системными разрешениями можно управлять в настройках iOS. Предоставляйте доступ для тех функций, которыми хотите пользоваться. Отказ от разрешения может ограничить работу функции, для которой этот доступ необходим.

Хранение и удаление

Работа с аккаунтом и управление файлами — разные действия. Если вы хотите узнать о хранящихся данных или обратиться по поводу их исправления либо удаления, напишите на contact-support@tuchkapp.ru и опишите свой запрос.

Для обращения достаточно изложить вопрос и указать сведения, позволяющие понять, какого аккаунта или файла он касается. Не отправляйте содержимое файлов, если оно не требуется для разбора вопроса.

Безопасность

Не передавайте пароли и коды входа третьим лицам. Проверяйте получателя перед отправкой ссылки на файл. При подозрении на посторонний доступ к аккаунту используйте доступные средства управления его безопасностью и обратитесь за помощью.

Этот сайт

Сайт Тучки размещён на GitHub Pages. Форма связи представлена как предварительный интерфейс: введённые имя и почта не отправляются, не сохраняются сайтом и очищаются при закрытии окна. Кнопка отправки пока недоступна. Для связи можно самостоятельно написать на contact-support@tuchkapp.ru. На сайте нет сторонних скриптов аналитики, внешних шрифтов или рекламных интеграций. Ресурсы загружаются с самого сайта.

При посещении сайта инфраструктура GitHub может получать технические данные запроса, включая IP-адрес, сведения браузера и журналы доступа. Обработка этих данных описана в политике конфиденциальности GitHub.

При переходе на сторонние сайты действуют правила соответствующих сервисов.
