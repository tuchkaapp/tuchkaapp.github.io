Какие данные нужны для работы приложения

Для входа, галереи и автозагрузки Тучка использует данные аккаунта и авторизации, фотографии и видео, доступ к которым вы разрешили, и сведения о медиа, необходимые для их отображения и загрузки. Самостоятельные разделы «Файлы», «Альбомы» и «Документы» находятся в разработке

Если вы обращаетесь по вопросам работы приложения или своих данных, сведения из обращения нужны для разбора вопроса. Не присылайте пароли, коды входа и лишние персональные данные

Где и как используются данные

Приложение обращается к серверной части сервиса для авторизации, отображения медиа в галерее и загрузки фотографий и видео. При включённой автозагрузке материалы с устройства передаются на сервер в пределах разрешённого доступа к фото

Перед включением автозагрузки проверьте, к каким фотографиям и видео у приложения есть доступ. Не загружайте материалы других людей без необходимых прав или согласия

Разрешения устройства

Доступом к фото можно управлять в настройках iOS. Галерея устройства и автозагрузка используют предоставленные разрешения. Отказ или ограничение доступа может повлиять на загрузку фотографий и видео. Работа в фоне зависит от ограничений iOS и настроек устройства

Хранение и удаление

Работа с аккаунтом и управление файлами — разные действия. Если вы хотите узнать о хранящихся данных или обратиться по поводу их исправления либо удаления, напишите на contact-support@tuchkapp.ru и опишите свой запрос

Для обращения достаточно изложить вопрос и указать сведения, позволяющие понять, какого аккаунта или файла он касается. Не отправляйте содержимое файлов, если оно не требуется для разбора вопроса

Безопасность

Не передавайте пароли и коды входа третьим лицам. Проверяйте получателя перед отправкой ссылки на файл. При подозрении на посторонний доступ к аккаунту используйте доступные средства управления его безопасностью и обратитесь за помощью

Этот сайт

Сайт Тучки размещён на GitHub Pages. Форма на сайте проверяет введённые имя и почту только в вашем браузере и показывает информационное окно. Данные формы не отправляются на сервер или по почте и не сохраняются сайтом. При закрытии формы поля очищаются. Для обращения к нам можно самостоятельно написать на contact-support@tuchkapp.ru; данные такого письма обрабатывает выбранный вами почтовый сервис. На сайте нет сторонних скриптов аналитики, внешних шрифтов, проверки Cloudflare Turnstile или рекламных интеграций. Ресурсы загружаются с самого сайта

При посещении сайта инфраструктура GitHub может получать технические данные запроса, включая IP-адрес, сведения браузера и журналы доступа. Обработка этих данных описана в политике конфиденциальности GitHub

При переходе на сторонние сайты действуют правила соответствующих сервисов
