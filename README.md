# Тучка

Адаптивный лендинг приложения Тучка для iOS. Статический HTML, CSS и JavaScript без внешних зависимостей. Иконка и знак взяты из бренд-концепции Тучки. Все изображения хранятся локально.

Текущая версия — предварительный просмотр дизайна. Интерфейс на иллюстрациях концептуальный; финальные экраны приложения готовятся. Отсутствующие ссылки на App Store, поддержку и документы не заменены вымышленными адресами.

## Локальный запуск

Требуется Node.js 20+:

```sh
node scripts/build.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. При открытии через file:// браузер может заблокировать site.config.json.

## GitHub Pages

В Settings → Pages выбрать Source: GitHub Actions. Push и PR запускают проверки. Actions → Check and publish Tuchka → Run workflow на main публикует сайт:

- `preview` — текущий макет с явной подписью концептов и noindex, nofollow.
- `release` — проверяет согласование бренда/скриншотов, обязательные HTTPS-ссылки и их доступность, затем разрешает индексирование.

Публичные файлы собираются в dist/. Относительные пути поддерживают как Pages аккаунта, так и Pages отдельного проекта.

## Обновление перед выпуском

В site.config.json заполнить проверенные адреса appStore, support, privacy, terms. Поддерживается только HTTPS; для App Store требуется apps.apple.com. Пока значение null, на сайте отображается статус подготовки.

После утверждения бренда и замены концептов снимками актуальной сборки обновить alt-тексты и подпись экрана, выставить brandApproved и screenshotsApproved в true. Проверить `node scripts/build.mjs --release`, затем публиковать в режиме release.
